## 🎬 Overview

The **Agentic Cinema** hackathon is a challenge hosted by Google Cloud and its partner ecosystem. The goal is to act as the "ecosystem architect" and build a functional autonomous agent—powered by **Gemini** and **Google Cloud Agent Builder**—that integrates a Partner Entity's product or MCP to power a real media & entertainment workflow. 

Rather than competing in a single massive pool, participants compete exclusively within the specific "studio track" of their chosen partner technology.

## 🛠 What to Build

Build a deterministic, multi-step agent that solves enterprise friction. The agent must:
1. **Cast Your Co-Star:** Choose one of the partner platforms (IBM, Grafana, Parallel, Clickhouse, or Replit) to hold the data or application workflows your agent interacts with.
2. **Build with Gemini Enterprise:** Build the agentic workflow on Google Cloud using the Gemini Enterprise Agent Platform.
3. **Connect the Systems:** Connect to the chosen partner tool using robust enterprise pipelines, API frameworks, or managed protocol adapters (like MCP servers).

## 📋 Submission Requirements

To successfully submit a project, the following are required:
- **Hosted URL:** A link to the hosted, functional project.
- **3-Minute Trailer (Demo Video):** A demo video showing the project/agent functioning as built (not a cinematic trailer). Must be on YouTube or Vimeo, publicly visible, and in English or with English subtitles.
- **Open-Source Repository:** A public code repository URL.
  - Must contain all source code, assets, and instructions needed to run.
  - Must demonstrate *actual runtime use* of Google Cloud and the chosen Partner's service (imported and called in code, not just named in the README).
  - Must include a complete open-source license file visible at the top of the repository page.
- **Track Selection:** Must explicitly select which partner track you are submitting to.
- **Devpost Form:** Completed submission form on Devpost.

## ⚖️ Judging Criteria

Projects will be evaluated on the following four criteria:
1. **Technological Implementation:** How well is the project built? How effectively does it use Google Cloud and the Partner services as part of the solution?
2. **Design:** Does the project deliver a complete, coherent product experience, or is it just a technical proof of concept?
3. **Potential Impact:** Does the project make a credible, specific case for solving a real problem for a real audience? Does the demonstrated solution actually address it?
4. **Quality of the Idea:** Is this a creative, non-obvious use of Google Cloud and the Partner services? Does the team show genuine understanding of the problem space?
